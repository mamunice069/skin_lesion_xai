## F7_part_b_summary

EXPLORATORY: settings and decision rules frozen on val before one test run; the HAM10000 test set had already been used by M4. SG = SmoothGrad-CAM, SC = Score-CAM, Mask = mask-guided fine-tuning. (a) hybrid vs ConvNeXt-T with the same method, (b) the method vs the hybrid's own Grad-CAM, (c) the method vs ConvNeXt-T's own Grad-CAM (descriptive), (d) mask-guided vs source hybrid, (e) mask-guided vs ConvNeXt-T Grad-CAM. Rule: met / no (not met) on val / test. Score-CAM uses a fixed 150-image subset; on ConvNeXt-T 27 / 150 (val) and 24 / 150 (test) of its maps are all zero (signed layer, positive weights), so Score-CAM (a) and (c) mostly measure that failure.
